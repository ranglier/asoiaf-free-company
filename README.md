# ASOIAF Free Company

Système de jeu non officiel pour [Foundry VTT](https://foundryvtt.com) (v14), pour jouer dans l'univers du Trône de Fer avec une compagnie de mercenaires.

- Fiches : personnage, PNJ allégé, Maison, Compagnie (modifiable par les joueurs).
- Tests à réserve de d6 (rang + dés bonus, on garde les meilleurs), degrés de réussite calculés, carte de chat lisible.
- Compagnie : ressources, services, unités, Cohésion, ravitaillement, avec les calculs automatiques.

## Installation

Dans Foundry, *Systèmes de jeu > Installer un système*, coller l'URL du manifeste de la dernière version :

```
https://github.com/<owner>/asoiaf-free-company/releases/latest/download/system.json
```

## Avertissement

Projet de fan, sans lien avec Green Ronin Publishing ni avec George R. R. Martin. Ce dépôt ne contient aucun texte des livres de règles : seulement des mécaniques, des libellés courts et des règles maison originales. Pour jouer, utilisez vos propres livres.
