# ASOIAF Free Company

Système de jeu non officiel pour [Foundry VTT](https://foundryvtt.com) (v14), pour jouer dans l'univers du Trône de Fer avec une compagnie de mercenaires.

- Fiches : personnage, PNJ, Maison, Compagnie (modifiable par les joueurs), dans un thème parchemin.
- Tests à réserve de d6 (rang + dés de bonus, on garde les meilleurs), dés de malus, degrés de réussite calculés, malus de blessures et de lésions automatiques.
- Attaque contre la cible : dégâts selon les degrés et la valeur d'armure, résolution par lésion ou blessure.
- Maison : possessions par ressource (investi / disponible), foyer, événements historiques, création guidée.
- Compagnie : ressources, services, unités, membres, Cohésion, ravitaillement, création guidée.

## Installation

Dans Foundry, *Systèmes de jeu > Installer un système*, coller l'URL du manifeste de la dernière version :

```
https://github.com/ranglier/asoiaf-free-company/releases/latest/download/system.json
```

## Avertissement

Projet de fan, sans lien avec Green Ronin Publishing ni avec George R. R. Martin. Le dépôt ne reproduit pas le texte des livres de règles. Il contient des mécaniques, des libellés courts, les tables chiffrées de création de Maison du livre de base (modificateurs des royaumes, fondations, événements historiques) et des règles maison originales (Compagnie de mercenaires). Pour jouer, utilisez vos propres livres.
